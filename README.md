# Ozon Promo Monitor

Мониторит товары на Ozon по артикулу (или прямой ссылке) и присылает уведомление
в Telegram, когда появляется акция со скидкой выше заданного порога.

## 1. Установка (один раз)

Нужен Python 3.9+. В папке проекта:

```
pip install -r requirements.txt
playwright install chromium
```

Второй командой Playwright скачает сам браузер (headless Chromium), которым
скрипт будет открывать страницы товаров.

## 2. Создание Telegram-бота (один раз, 2 минуты)

1. В Telegram напиши **@BotFather** → команда `/newbot` → придумай имя и username бота.
   BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
2. Напиши своему новому боту любое сообщение (например «привет») — это нужно,
   чтобы бот вообще мог тебе что-то прислать.
3. Узнай свой **chat_id**: открой в браузере (пока бот получил от тебя хоть одно сообщение)

   ```
   https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
   ```

   В ответе (JSON) найди `"chat":{"id":123456789,...}` — это число и есть твой chat_id.
   Если ответ пустой — напиши боту ещё раз сообщение и обнови страницу.

## 3. Настройка

Скопируй `config.example.json` в `config.json` и заполни:

```json
{
  "telegram": {
    "bot_token": "токен из BotFather",
    "chat_id": "твой chat_id"
  },
  "poll_interval_minutes": 5,
  "default_threshold_percent": 20,
  "items": [
    {
      "name": "Наушники Sony WH-1000XM5",
      "article": "123456789",
      "url": null,
      "threshold_percent": null,
      "target_price": null
    }
  ]
}
```

Про поля товара:
- `article` — числовой артикул товара. Скрипт сам соберёт ссылку вида
  `https://www.ozon.ru/product/<article>/`.
- `url` — если у тебя уже есть прямая ссылка на товар, укажи её здесь, а `article`
  оставь `null`. Это надёжнее, чем угадывать ссылку по одному артикулу.
- `threshold_percent` — свой порог скидки для конкретного товара (в %), либо
  `null`, чтобы использовать `default_threshold_percent` из общих настроек.
- `target_price` — необязательно: абсолютная цена в рублях, при падении ниже
  которой тоже придёт уведомление (независимо от процента скидки).

Можно добавить сколько угодно товаров в список `items`.

## 4. Проверка настроек

### Сначала — без Telegram вообще

Чтобы проверить, что программа правильно находит цену и определяет акцию,
Telegram-бот пока не нужен. Заполни в `config.json` только `items` (артикул
или ссылку на товар), а поля `telegram` можно оставить как есть — и запусти:

```
python ozon_monitor.py --config config.json --once --debug --no-notify
```

`--no-notify` полностью выключает отправку в Telegram — вместо реального
сообщения программа просто напишет в консоли, что уведомление было бы
отправлено, и с каким текстом. `--once` — один проход без ожидания.
`--debug` — сохранить HTML и скриншот страницы в папку `debug/`.

Смотри на вывод в консоли:
- `цена=..., было=..., скидка=...%` — значит цена нашлась, всё работает. Если
  при этом видно `АКЦИЯ ПОДХОДИТ (уведомление не отправлено...)` — значит и
  логика определения акции сработала правильно.
- `Не удалось найти цену на странице` — значит вёрстка Ozon на этой странице не
  совпала с тем, что ищет скрипт (см. раздел «Если парсинг перестал находить
  цену» ниже). Загляни в папку `debug/` — там сохранятся HTML и скриншот
  страницы, какими их увидел скрипт.

### Потом — с реальной отправкой в Telegram

Когда убедишься, что цена находится верно, заполни `telegram.bot_token` и
`chat_id` (см. шаг 2 выше) и повтори проверку уже без `--no-notify`:

```
python ozon_monitor.py --config config.json --once --debug
```

Если бот не прислал тестовое сообщение, но в консоли видно
`скидка=... акция_подходит=True` — значит проблема в токене/chat_id, проверь
шаг 2.

## 5. Постоянный мониторинг

Самый простой способ — двойным щелчком запустить **`start.bat`**. Он сам:
- проверит, что Python установлен;
- при первом запуске создаст `config.json` из примера и откроет его в
  блокноте, чтобы ты вписал токен бота, chat_id и артикулы (после — сохрани
  файл и запусти `start.bat` ещё раз);
- поставит зависимости (`pip install`) и браузер Playwright, если их ещё нет;
- запустит мониторинг и будет сам перезапускать скрипт, если он вдруг упадёт.

Оставь это окно открытым — пока оно работает, идёт мониторинг. Компьютер не
должен уходить в сон/гибернацию — при необходимости отключи это в настройках
электропитания Windows на время мониторинга.

Если зависимости и `config.json` уже готовы и просто хочешь перезапустить
мониторинг без повторной проверки установки — можно использовать более лёгкий
`run_forever.bat`, либо запустить вручную:

```
python ozon_monitor.py --config config.json
```

## Если парсинг перестал находить цену

У Ozon нет официального API для получения цены по произвольному артикулу,
поэтому скрипт читает то, что видно на странице обычному браузеру — а вёрстка
сайта время от времени меняется. Если `--debug` показывает, что цена есть на
скриншоте, но скрипт её не находит:

1. Открой `debug/<артикул>.html` и найди в нём, в каком элементе теперь лежит
   цена (обычно достаточно поискать `₽` по файлу).
2. В `ozon_monitor.py` поправь селектор `'[data-widget="webPrice"]'` в функции
   `fetch_price_block_text` на актуальный, либо расширь регулярку `PRICE_RE`,
   если поменялся формат отображения цены.

### Если вместо товара показывается «Похоже, нет соединения»

Это не сбой сети, а антибот-проверка Ozon (домен `abt-challenge` в
`debug/<артикул>.html`, кнопка «Обновить страницу») — сайт заподозрил, что
запрос идёт не от обычного человека в браузере, а от автоматизации. Скрипт
теперь сам пытается один раз нажать «Обновить страницу» и подождать, но если
это не помогает:

- Проверь/поставь в `config.json` `"headless": false` (это значение по
  умолчанию уже в `config.example.json`) — headless-режим (браузер без
  видимого окна) чаще вызывает подозрение защиты, чем обычный видимый
  браузер. При `headless: false` во время проверки будет ненадолго
  открываться окно Chromium — это нормально.
- Не ставь `poll_interval_minutes` слишком маленьким и не добавляй сразу
  много товаров — чем чаще и больше запросов с одного и того же ПК, тем выше
  риск повторной блокировки.
- Если блокировка идёт стабильно даже с видимым браузером — открой этот же
  товар вручную в обычном Chrome с этого компьютера один раз (это помогает
  «прогреть» IP/куки), и попробуй снова.

## Структура файлов

- `ozon_monitor.py` — основной скрипт
- `config.json` — твои настройки (создаётся из `config.example.json`, не
  публикуй его — в нём токен бота)
- `state.json` — создаётся автоматически, хранит последнюю цену и флаг
  «уже уведомил» по каждому товару, чтобы не слать одно и то же сообщение
  повторно, пока акция активна
- `debug/` — создаётся только с флагом `--debug`
